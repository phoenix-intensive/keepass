Professional Edition (2.x)

Free

The latest version of KeePass with advanced features and modern interface. Recommended for most users.

  • AES-256 and ChaCha20 encryption
  • Plugin support
  • Advanced auto-type
  • Key file and Windows user account authentication
  • Secure desktop mode
  • Extensive import/export options
  • Powerful search and grouping
  • Regular updates
Windows Linux (Mono) macOS (Mono)

Classic Edition (1.x)

Free

The legacy version of KeePass with a smaller footprint and simpler interface. Suitable for older systems.

  • AES-256 encryption
  • Basic plugin support
  • Standard auto-type
  • Key file authentication
  • Basic import/export options
  • Smaller memory footprint
  • Compatible with older Windows versions
  • Maintenance updates only
Windows
Download Classic Edition

Portable Edition

Free

Run KeePass directly from a USB drive or any folder without installation. Perfect for use on multiple computers.

  • No installation required
  • Run from any folder or USB drive
  • All features of Professional Edition
  • Leaves no traces on host computer
  • Perfect for travel or shared computers
  • Available for both Professional and Classic
